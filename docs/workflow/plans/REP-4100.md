# Plan de Implementación Técnica: REP-4100

## 1. Módulos y Fases de Desarrollo

### Fase 1: Shell de Aplicación y Navegación
- Crear `src/components/layout/AppLayout.jsx` con Topbar y Bottom Navigation Bar de 5 botones.
- Añadir estados activos (`isActive`), badges de notificación y animación táctil.

### Fase 2: Componente de Mapa Ciudadano
- Crear `src/components/map/CitizenMap.jsx` con importación de `maplibre-gl` y sus estilos.
- Configurar viewport centrado en coordenadas default (ej. Buenos Aires / Argentina: `[-58.3816, -34.6037]`, zoom 13).
- Implementar controles flotantes: Botón de filtros (`tune`) y leyenda de calor.
- Soporte para inicialización segura en SSR/Test (mock fallback en entornos sin WebGL).

### Fase 3: Páginas Principales
- `MapPage.jsx`: Vista del mapa sobre `AppLayout`.
- `ReportsPage.jsx`: Vista "Mis reportes" con listado de reclamos.
- `NewsPage.jsx`: Vista "Novedades" con avisos comunitarios.
- `ProfilePage.jsx`: Vista "Perfil" con datos del ciudadano, consentimientos y logout.

### Fase 4: Enrutador y Redirecciones
- Actualizar `src/App.jsx` para declarar las nuevas rutas protegidas y redirigir `/app` hacia `/mapa`.
- Actualizar `src/pages/TermsAndPermissionsPage.jsx` para navegar a `/mapa` tras aceptar permisos.

### Fase 5: Pruebas y Quality Gates
- Crear `src/test/MapFlow.test.jsx`.
- Ejecutar `pnpm test` y `pnpm run build`.

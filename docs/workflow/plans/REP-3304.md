# Plan de Implementación — REP-3304: Configurar Vercel Preview por Rama

## 1. Resumen

Implementar la configuración necesaria para que el repositorio `reportalo.mvp` genere automáticamente vistas previas en Vercel por cada rama y Pull Request, documentando el flujo de trabajo para el Project Leader (Matias) y el tester de QA (Ivo).

## 3. Estrategia de Implementación

1. **Estructura y Trazabilidad**: Crear todos los documentos del workflow y registrar en `resume.md`.
2. **Configuración Vercel**: Definir `vercel.json` con configuración compatible y segura para previews.
3. **Validaciones**: Verificar sintaxis YAML y JSON localmente.
4. **Procedimiento de Despliegue**: Instrucciones para vincular el repositorio en `vercel.com` y comprobar el primer preview.

## 4. Estrategia de Rollback

Si una rama o PR presenta un fallo en el preview, no afecta `main` ni producción. En caso de error en configuración de Vercel, se revierte el commit correspondiente en la rama de trabajo.

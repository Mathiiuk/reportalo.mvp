# REP-3607 — Plan: Términos modo consultivo desde Perfil

## Descripción

Corrección de la regresión donde navegar a `/terminos` desde `/perfil` muestra el flujo
de aceptación obligatoria incluso cuando el usuario ya aceptó los T&C vigentes.

La solución introduce un **modo consultivo** en `TermsAndPermissionsPage` activado
mediante `location.state.consultaDesde`, y ajusta el guard de routing para permitir
el acceso a `/terminos` en ese modo.

---

## Archivos modificados

### `src/pages/ProfilePage.jsx` — [MODIFY]

**Cambio:** Al presionar "Revisar términos y permisos →", navegar con `state`:
```js
navigate('/terminos', { state: { consultaDesde: 'perfil' } });
```
También mostrar los datos reales del consentimiento (versión + fecha) usando
`getTermsRecord(user?.id)` para enriquecer la tarjeta de Privacidad y Términos.

---

### `src/pages/TermsAndPermissionsPage.jsx` — [MODIFY]

**Cambio:** Detectar `location.state?.consultaDesde` al inicio del componente.
Si `consultaDesde === 'perfil'`:

1. **No mostrar** el checkbox de aceptación explícita.
2. **No mostrar** el botón "Aceptar y continuar".
3. **No mostrar** el botón "Rechazar".
4. **Mostrar** un banner de "Ya aceptaste esta versión" con fecha y versión.
5. **Mostrar** el botón de cierre/volver a Perfil (secundario, no destructivo).
6. Si hay `isOutdated`, mostrar banner informativo de nueva versión disponible,
   con opción de aceptar la nueva versión o volver sin cambios.
7. El Paso 2 (Permisos) **no se muestra** en modo consultivo.

---

### `src/App.jsx` — [MODIFY]

**Cambio:** Ajustar el guard `ProtectedRoute` para que cuando `termsAccepted === true`
y el pathname es `/terminos`, permita el acceso si la navegación trae
`location.state?.consultaDesde`. 

> **Nota:** `useLocation()` ya está disponible en `ProtectedRoute`. El state se puede
> inspeccionar ahí para NO redirigir a `/mapa` cuando es una consulta voluntaria.

---

## Flujo de estados UI en modo consultivo

```
/perfil → "Revisar términos" → navigate('/terminos', { state: { consultaDesde: 'perfil' } })
  └── TermsAndPermissionsPage
        ├── termsAccepted=true, mismaVersion → Banner verde "Ya aceptaste v1.3 el DD/MM/YYYY"
        │     └── Botón "← Volver a perfil"
        └── termsAccepted=true, versión desactualizada → Banner azul "Nueva versión disponible"
              ├── Botón "Aceptar versión 1.3" (flujo normal de re-aceptación)
              └── Botón "Volver sin aceptar"
```

## Plan de Tests

Ver `docs/workflow/tests/REP-3607.md` para los escenarios BDD completos.

**Verificación manual:**
1. Aceptar T&C como usuario nuevo → flujo normal sin cambios.
2. Ir a `/perfil` → presionar "Revisar términos" → verificar modo consultivo (sin checkbox).
3. Verificar que el estado de consentimiento en `localStorage` no cambió tras la visita.
4. Simular T&C desactualizados → verificar banner de nueva versión en modo consultivo.
5. Simular usuario sin aceptación → verificar flujo de aceptación intacto.

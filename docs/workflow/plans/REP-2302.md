# Plan Técnico de Arquitectura: REP-2302

## 1. Módulos y Componentes

1. **`src/services/locationService.js`:**
   - Métodos: `getUserCoordinates(options)`, `getGeolocationPermissionState()`, `watchUserCoordinates(onSuccess, onError, options)`.
   - Constantes de estado `LOCATION_STATUS`.
   - Directivas explícitas de no-uso de EXIF.

2. **`src/hooks/useGeolocation.js`:**
   - Hook de React para exponer estado reactivo de ubicación a componentes de mapa y formularios.

3. **`src/test/LocationService.test.jsx`:**
   - Suite con pruebas unitarias para todas las funciones del servicio y el hook.

# Plan de Implementación: REP-3532

## 1. Módulos y Archivos a Modificar / Crear

1. **`src/services/termsService.js` [NUEVO]:**
   - Constante `CURRENT_TERMS_VERSION = '1.2'`.
   - Métodos:
     - `hasAcceptedCurrentTerms(userId)`: verifica versión y timestamp.
     - `recordTermsAcceptance(userId, permissions)`: persiste consentimiento auditable.
     - `getTermsRecord(userId)`: retorna el objeto de consentimiento.

2. **`src/pages/TermsAndPermissionsPage.jsx` [NUEVO]:**
   - Flujo de 2 pasos continuos:
     - **Paso 1:** Pantalla de Términos y Privacidad (con modal de texto legal completo, checkbox de aceptación y validación).
     - **Paso 2:** Pantalla de Activación de Permisos (Cámara y Ubicación con switches interactivos, banner verde de seguridad, botones Continuar y Ahora no).
   - Layout responsive: Mobile full-bleed y Desktop con split-screen de dos columnas con Header institucional y Sidebar informativa.

3. **`src/pages/BlankAppPage.jsx` (Integración con el Dashboard de Reportes):**
   - Botón interactivo *"Crear nuevo reporte"*.
   - Si no ha aceptado la versión vigente (v1.2), abre/redirige al flujo `/terminos`.
   - Si ya aceptó, muestra confirmación de permisos listos y permite proceder al reporte.
   - Badge visual del estado del consentimiento de términos (v1.2).

4. **`src/App.jsx`:**
   - Registrar la ruta `/terminos`.

5. **`src/test/TermsFlow.test.jsx` [NUEVO]:**
   - Matriz de pruebas unitarias cubriendo aceptación inicial, checkbox obligatorio, permisos, rechazo ("Ahora no"), cambio de versión y persistencia.

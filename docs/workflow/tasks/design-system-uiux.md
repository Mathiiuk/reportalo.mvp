## Objetivo

Implementar el Design System UI/UX completo de Reportalo, estableciendo una base visual coherente, moderna y consistente para toda la aplicación.

## Alcance

- Cambio de tipografía: Inter → Manrope

- Material Symbols Rounded como set de iconos
- CSS custom properties como design tokens
- Actualización de Tailwind config
- Actualización de todos los componentes existentes
- Base CSS con estilos del design system

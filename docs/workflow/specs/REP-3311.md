# Specification — REP-3311

## 1. Objetivo

Implementar el flujo completo de Magic Link (autenticación por email sin contraseña) usando Supabase OTP, incluyendo envío de email, verificación de token en callback, y redirección según estado del usuario.

## 2. Problema actual

ElHomePage tenía un formulario de email que llamaba a `signInWithEmail()`, pero esta función no existía en authService.js ni AuthContext.jsx. No había ruta de callback ni verificación de tokens. El flujo lanzaba error en runtime.

## 3. Resultado esperado

- Usuario ingresa email → recibe link mágico → hace click → sesión establecida
- Redirección automática a /map o /onboarding según estado del usuario
- Manejo de errores (link expirado, inválido, etc.)

## 4. Alcance

### Incluido
- `signInWithEmail()` en authService.js usando `supabase.auth.signInWithOtp()`
- `signInWithEmail` expuesto en AuthContext
- Componente `AuthCallback.jsx` para manejar el redirect
- Ruta `/auth/callback` pública
- `cleanAuthCallbackUrl()` mejorada para limpiar tokens de query params
- UI de error con botón de retorno

### No incluido
- Configuración del Supabase Dashboard (responsabilidad del equipo)
- Templates de email personalizados
- Rate limiting de envío de emails (Supabase lo maneja)

## 5. Criterios de aceptación

- [x] AC-01: signInWithEmail llama signInWithOtp con emailRedirectTo a /auth/callback
- [x] AC-02: AuthContext expone signInWithEmail
- [x] AC-03: Ruta /auth/callback agregada
- [x] AC-04: AuthCallback procesa token_hash y type
- [x] AC-05: cleanAuthCallbackUrl limpia tokens de URL
- [x] AC-06: Redirección según onboarding status
- [x] AC-07: UI de error para links expirados/inválidos
- [x] AC-08: HomePage signInWithEmail funcionando

## 6. Restricciones

- PKCE flow (ya configurado)
- No romper Google OAuth
- Supabase Dashboard debe tener Redirect URLs configuradas

## 7. Dependencias

- @supabase/supabase-js ^2.49
- Supabase Auth Email provider habilitado
- Redirect URL configurada en Supabase

## 8. Riesgos

- Si /auth/callback no está en Redirect URLs de Supabase, el link no funciona
- Email puede caer en spam si el dominio no está verificado

## 9. Configuración Supabase Requerida

1. Authentication > URL Configuration > Redirect URLs: agregar `https://dominio/auth/callback`
2. Authentication > Email Templates: personalizar template
3. Authentication > Providers > Email: habilitado

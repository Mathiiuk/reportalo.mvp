# Specification — REP-3313

## 1. Objetivo

Agregar tests de QA para los casos de sesión activa, logout y sesión expirada, cumpliendo el AC6 de REP-3520.

## 2. Problema

No existen tests que cubran:
- Persistencia de sesión al recargar
- Redirección de usuario autenticado lejos del login
- Funcionamiento del botón de cerrar sesión
- Redirección de ProtectedRoute cuando la sesión expira

## 3. Criterios de aceptación

- [x] AC-01: Test sesión activa
- [x] AC-02: Test logout
- [x] AC-03: Test sesión expirada
- [x] AC-04: Todos pasan

## 4. Trazabilidad

Audit REP-3520 → AC6 FAIL → REP-3313

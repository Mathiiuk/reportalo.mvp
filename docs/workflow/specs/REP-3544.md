# Especificación de Requerimientos: REP-3544

## 1. Contexto y Objetivo
Implementar la experiencia de usuario y validación visual para el caso en que **no se tilden los términos y privacidad**, el manejo de la acción **"Rechazar"** y la habilitación de la **exploración ciudadana sin consentimiento previo** dentro de Reportalo MVP.

Esta tarea complementa y refina la épica REP-3532, asegurando que:
- El usuario reciba retroalimentación visual inmediata si omite marcar la casilla obligatoria de consentimiento.
- El usuario pueda rechazar los términos o salir al panel general (`/app`) para explorar la plataforma.
- La creación de reportes quede debidamente bloqueada hasta que exista un consentimiento registrado de la versión vigente (v1.2).

---

## 2. Historias de Usuario
- **Como** ciudadano en la pantalla de términos,
- **Quiero** ver una indicación clara y precisa si intento continuar sin marcar la casilla de aceptación,
- **Para** comprender exactamente qué requisito falta para avanzar.

- **Como** ciudadano que no desea aceptar los términos en este momento,
- **Quiero** contar con una opción explícita de "Rechazar" para salir al dashboard,
- **Para** poder explorar la aplicación conociendo que la emisión de reclamos requerirá mi consentimiento posterior.

---

## 3. Criterios de Aceptación Detallados

1. **AC-01 (Banner de Advertencia y Checkbox de Error):**
   - Si el usuario presiona *"Aceptar y continuar"* con el checkbox desmarcado:
     - Se despliega el banner de alerta:
       - Fondo: `#FFF2E0` (`rgb(255, 242, 224)`), borde: `#F7E2C8` (`rgb(247, 226, 200)`), radio: `12px`, padding: `11px 12px`.
       - Icono: `error` (Material Symbols Rounded, 16px, color `#8A6A3E` / `rgb(138, 106, 62)`).
       - Texto: `"La casilla es obligatoria. Marcala para poder continuar."` (font-semibold, 10.5px / 1.45 line-height, color `#8A6A3E`).
     - El checkbox muestra un contorno de color naranja/ámbar: `border: 2px solid #E07C1A` (`rgb(224, 124, 26)`).

2. **AC-02 (Limpieza de Error al Tildar):**
   - En el instante en que el usuario marca el checkbox, el banner de advertencia se oculta y el borde naranja desaparece, activando el fondo azul `#1E6FCB` con tilde blanca.
   - El botón *"Aceptar y continuar"* pasa a estado activo azul `#1E6FCB` con sombra y efectos interactivos.

3. **AC-03 (Acción Rechazar):**
   - Se muestra el botón de texto `"Rechazar"` ubicado debajo de *"Aceptar y continuar"* (color `#8593A2`, hover `#263249`).
   - Al hacer clic en *"Rechazar"*, se notifica con un toast informativo y se navega a `/app` sin registrar consentimiento en el almacenamiento local.

4. **AC-04 (Exploración sin Consentimiento):**
   - El usuario puede navegar por `/app` libremente.
   - En `/app`, se muestra el badge `"Términos v1.2 pendientes"` (punto ámbar).
   - Al pulsar *"Crear nuevo reporte"*, se verifica el consentimiento; al no existir, se emite una advertencia y se redirige a `/terminos`.

5. **AC-05 (Cabecera y Badges Institucionales):**
   - La cabecera presenta el título `"Términos y privacidad"` (color `#243447`, peso 800) y el badge `"VIGENTE"` (`bg-[#E3F5EC]` / `text-[#2C7A55]`) junto a `"Versión 1.2 · desde 08/2026"` (`text-[#9AA7B5]`).

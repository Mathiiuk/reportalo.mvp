# Especificación de Requerimientos: REP-2300

## 1. Historia de Usuario
Como ciudadano, quiero que Reportalo detecte mi ubicación al ingresar a la experiencia principal para contextualizar el mapa y preparar la ubicación del futuro reporte.

---

## 2. Criterios de Aceptación

1. **CA-01 (Solicitud justificada):** La aplicación solicita permiso de ubicación solo cuando es necesario y explica su uso de forma clara.
2. **CA-02 (Ubicación válida con permiso concedido):** Con permiso concedido se obtiene una ubicación válida del dispositivo (`[longitude, latitude]`).
3. **CA-03 (Contextualización del mapa):** El mapa se centra en la ubicación del usuario y dibuja un marcador distintivo ("Tu ubicación").
4. **CA-04 (Manejo de permiso denegado):** Si el permiso se deniega, la pantalla principal sigue siendo utilizable, centra en la posición por defecto (CABA/Avellaneda) y muestra un banner informativo no bloqueante.
5. **CA-05 (No bloqueo de User Journey):** No se bloquea de forma irreversible el User Journey por denegar el permiso; el usuario puede continuar navegando y reintentar la detección.
6. **CA-06 (Validación QA de escenarios):** QA valida los 3 estados: permiso concedido, permiso denegado y servicio no disponible/timeout.

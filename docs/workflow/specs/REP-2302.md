# Especificación Técnica: REP-2302

## 1. Alcance Técnico
1. Integrar la API nativa de geolocalización del navegador (`navigator.geolocation`) y la API de consulta de permisos (`navigator.permissions.query`).
2. Obtener coordenadas del dispositivo con precisión (`accuracy`) cuando el usuario concede permiso.
3. Manejar de forma desacoplada y resiliente los estados de permiso denegado, no disponible, timeout y navegador no compatible.
4. Exponer el resultado a la pantalla principal/mapa mediante un hook y servicio reutilizables sin bloquear el flujo ante errores.
5. **Regla de Privacidad Anti-EXIF:** No utilizar metadatos EXIF de fotografías como fuente de ubicación funcional.

---

## 2. Criterios de Finalización
- La tarea se considera terminada cuando `locationService.js` y `useGeolocation.js` están 100% integrados, testeados y listos para respaldar la demostración de REP-2300 y la validación REP-3440 en Sprint 10.

# Framer Motion Animator Skill

Creación de animaciones fluidas, transiciones móviles, menú desplegable flotante (FAB speed dial) y micro-interacciones de diseño UI con física de resortes (`spring`).

## 🛠️ Principios de Animación:
1. **Transiciones Suaves (`FadeIn`, `SlideUp`)**: Animación progresiva en la carga de componentes.
2. **Micro-interacciones al Interactuar (`whileHover`, `whileTap`)**: Feedback táctil visual con escalado sutil (`scale: 1.02`).
3. **AnimatePresence para Modales y Menús Flotantes**: Cierre y apertura animados sin cortes abruptos en el DOM.

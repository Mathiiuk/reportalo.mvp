# Technical SEO Audit Skill

Auditoría técnica automática con SEOmator CLI para evaluar 251 reglas en 20 categorías.

## Categorías Auditadas:
- Core SEO, Performance (LCP, CLS, INP), Enlaces rotos, Imágenes y Alt text, Seguridad (HTTPS, HSTS, CSP), Technical SEO (sitemap, robots.txt), Schema.org JSON-LD, Accesibilidad (ARIA), Redirecciones 301/302, Preparación para IA (llms.txt, semantic HTML).

## Comando de Auditoría:
```bash
npx @seomator/seo-audit audit https://www.uturno.com --format llm
```

# 📈 Marketing Analytics Skill

Implementación y auditoría de sistemas de analítica y medición para la toma de decisiones informadas.

## 📌 Principios:
1. **Medir para Decidir**: Medir eventos que respalden decisiones estratégicas de negocio.
2. **Convención de Nombres (Objeto-Acción)**: `signup_completed`, `booking_completed`, `cta_clicked`.
3. **Parametrización UTM Uniforme**: `utm_source`, `utm_medium`, `utm_campaign`.

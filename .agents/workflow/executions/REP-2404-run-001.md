## 2. Alcance Implementado

### Storage Buckets y Políticas RLS (`supabase/schema.sql`)
1. **Bucket `evidence-quarantine`**:
   - Acceso: `public = false` (privado transitorio con cifrado en reposo).
   - Inserción: Permitida para usuarios autenticados.
   - Lectura / Eliminación: Exclusiva para `service_role` (Edge Functions / Backend).
2. **Bucket `report-evidences`**:
   - Acceso: `public = true` (solo imágenes anonimizadas y sanitizadas).
   - Inserción: Exclusiva para `service_role`.
   - Lectura: Pública para visualización en mapa y detalle de reportes.

### Edge Function Server-Side (`supabase/functions/quarantine-anonymize/index.ts`)
1. **Aislamiento**: Descarga la imagen original desde `evidence-quarantine`.
2. **Sanitización EXIF**: Remueve metadatos geográficos y marcas de cámara (APP1/EXIF).
3. **Detección y Anonimización**:
   - Google Vision API (`FACE_DETECTION`, `TEXT_DETECTION`).
   - Fallback de heurística visual determinística si no se suministra API key de Vision.
   - Difuminado de rostros y patentes vehiculares con Canvas/Sharp.
4. **Publicación**: Sube la imagen anonimizada en formato optimizado WebP al bucket `report-evidences`.
5. **Principio Fail-Safe Inquebrantable**:
   - Bloque `finally` forzoso que elimina de forma inmediata e irrecuperable el archivo original en `evidence-quarantine`, tanto ante éxito como ante cualquier excepción.

### Servicio Cliente (`src/services/quarantinePipelineService.js`)
- `uploadToQuarantine(file, clientSideId)`: Sube la evidencia al bucket transitorio.
- `processEvidenceThroughQuarantine({ file, clientSideId, simulateError })`: Orquesta el pipeline server-side con manejo de errores y fallback local determinístico.
- `processAllEvidencesThroughQuarantine({ evidenceList, clientSideId, simulateError, onProgress })`: Procesamiento por lotes con actualización de progreso y soporte fail-safe.
- `sanitizeImageMetadataLocally(file)`: Limpieza binaria cliente de metadatos EXIF.

### Integración UI & UX Coloquial (`ReportProcessingScreen.jsx` & `NewReportPage.jsx`)
- Sincronización de progreso dinámico con los pasos del pipeline de privacidad.
- Vista fail-safe ante fallos de servidor:
  - Mensaje coloquial y comprensible para el vecino ("No pudimos proteger tu foto", "La foto original se eliminó para cuidar tu privacidad").
  - Botones de acción: "Reintentar protección" y "Volver a sacar la foto".
- Retrocompatibilidad total con los flujos de captura y envío existentes.

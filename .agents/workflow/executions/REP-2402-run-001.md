## 1. Resumen de Implementación
Se implementó la pantalla interactiva `EvidencePreviewScreen` en el flujo de creación de reportes (`NewReportPage`), permitiendo al vecino:
1. Inspeccionar de manera visual la imagen resultante del pipeline server-side de cuarentena y anonimización.
2. Comprobar las zonas difuminadas (rostros y patentes vehiculares) con insignias de verificación de privacidad.
3. Hacer zoom táctil a pantalla completa para examinar los detalles antes de comprometer el reporte público.
4. Descartar la imagen y recapturarla si el difuminado afectó partes cruciales del reporte.
5. Confirmar y enviar formalmente el reporte, avanzando a la pantalla final de éxito `ReportSuccessScreen` donde se purga el borrador de IndexedDB.

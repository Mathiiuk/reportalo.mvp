## 3. Hallazgo para decidir (fuera de los criterios)
Si la lectura de los reportes **falla** (sin red, error de la base), `/reportes` muestra el estado vacío «**Todavía no enviaste reportes**» y le ofrece «Hacer mi primer reporte»: el ciudadano puede creer que perdió sus reportes. Comprobado con una prueba descartable. El código ignora el error (`if (result.success) …`) y deja la lista vacía. **Propuesta:** un estado de error propio («No pudimos cargar tus reportes. Probá de nuevo») con reintento, distinto del vacío (el UJ v3.3 M26-M28 ya distingue «cargando / vacío / error»). No se tocó: es un cambio de comportamiento que conviene aprobar.

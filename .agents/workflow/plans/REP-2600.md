# Plan Técnico de Arquitectura: REP-2600

## 1. Módulos y Componentes

1. **`src/data/mockReports.js`:**
   - Centralizar el dataset de reportes de prueba georreferenciados en CABA y Avellaneda.
   - Campos: `id`, `title`, `category`, `status`, `coordinates: [lng, lat]`, `address`, `date`.

2. **`src/components/map/CitizenMap.jsx`:**
   - Crear marcadores HTML dinámicos para MapLibre con estilo de pin redondeado y color según estado.
   - Tarjeta flotante inferior (*Floating Report Card*) para mostrar categoría, título, dirección, estado y fecha al hacer clic en un pin.
   - Sincronización reactiva con el menú de filtros del mapa.
   - Banner de estado vacío flotante cuando ningún reporte coincide con el filtro activo.

3. **`src/components/layout/AppLayout.jsx`:**
   - Manejo del botón de la cámara para notificar al usuario sobre el Sprint 11.

4. **`src/test/MapFlow.test.jsx`:**
   - Cobertura de tests unitarios y de integración para marcadores, popups, filtros y navegación.

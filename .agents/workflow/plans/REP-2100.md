# Implementation Plan — REP-2100

## 1. Resumen

Implementación del flujo de inicio de sesión con Google OAuth para Reportalo MVP. Se desarrollarán las vistas de Bienvenida y Login con fidelidad visual respecto al diseño proporcionado, se configurará el contexto de autenticación con Supabase, y se integrará la navegación con React Router y pruebas unitarias con Vitest.

## 2. Repositorio inspeccionado

- Stack: React 18, Vite 6, Tailwind CSS 3.4, Supabase JS 2.49
- Runtime: Node.js / Browser ESM
- Package manager: npm
- Branch base: `main`
- Branch de trabajo: `feat/REP-2100-login-google`

## 4. Estrategia de implementación

1. **Configuración de base:** `vite.config.js`, `tailwind.config.js`, `postcss.config.js`, `index.html` con fuentes Manrope y Material Symbols Rounded.
2. **Capa de Autenticación:** `supabaseClient.js` con fallback seguro, `AuthContext` con `signInWithGoogle` (`provider: 'google'`), manejo de errores y limpieza de hashes/tokens en la URL (`replaceState`).
3. **Vistas Mobile-First:**
   - `WelcomePage`: UI exacta con gradiente azul `#1e6fcb` a `#15539e`, pin_drop, títulos, bullets (`shield`, `auto_awesome`, `map`), botón `Comenzar`.
   - `LoginPage`: UI exacta con `arrow_back`, branding `Reportalo`, botón `Continuar con Google`, divisor `o`, input de correo maquetado para enlace mágico, botón de envío, y footer con `shield`.
   - `BlankAppPage`: Vista protegida en blanco para usuario autenticado con datos de email/id y botón `Cerrar sesión`.
4. **Enrutamiento:** `App.jsx` con rutas `/`, `/login`, `/app`, gestionando redirección automática si ya existe sesión activa.
5. **Pruebas y QA:** Vitest con mocks controlados de Supabase para validar renderizado, llamadas a `signInWithOAuth`, manejo de errores y protección de rutas.

## 5. Seguridad

- Los tokens y fragmentos hash generados por OAuth se consumen y se remueven de la barra de direcciones inmediatamente con `window.history.replaceState`.
- Las claves públicas de Supabase se leen desde variables de entorno con prefijo `VITE_`.
- Ningún dato sensible o secreto de rol de servicio se expone en el cliente.

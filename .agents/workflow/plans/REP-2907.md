# Plan de Implementación — REP-2907

## 1. Módulos y Tareas Técnicas
1. **Definición de DDL y Seed SQL en Supabase (`supabase/rag_normativas.sql`):**
   - Asegurar columnas de metadatos de trazabilidad en la tabla `normativas`.
   - Política RLS pública de lectura para ciudadanos y clientes.
   - Definición de la función RPC `match_normativas` con soporte para ranking por similitud y metadatos.
   - Inserción de las 8 normas iniciales estructuradas.

2. **Servicio JavaScript (`src/services/legalRagService.js`):**
   - Estructura de datos in-memory con el corpus de 8 normas y metadatos completos.
   - Vectorizador semántico determinístico local (basado en embeddings normalizados) para entornos DEV/Test.
   - Cliente de llamada RPC a Supabase (`supabase.rpc('match_normativas', ...)`).
   - Función `searchRelevantNormativas({ query, category, threshold, limit })`.
   - Función de evaluación y benchmark `benchmarkRagQueries(testCases)` que calcula latencia, precisión y similitudes.

3. **Pruebas Automatizadas (`src/test/LegalRagService.test.js`):**
   - Verificación de los 8 chunks normativos y campos obligatorios.
   - Tests de recuperación para las consultas de `REP-3764` (Positivas, Ambiguas y Fuera de dominio).
   - Tests de degradación elegante cuando Supabase no está conectado o ante consultas vacías.
   - Validación de latencia en milisegundos (< 100ms en emulador local, registro para reporte).

4. **Ejecución y Verificación de Quality Gates:**
   - `pnpm test` (verificando que pasen los 23 suites y >125 tests).
   - `pnpm run build` (validar bundle limpio).
   - Generación de evidencia en `.agents/workflow/executions/REP-2907-run-001.md`.

# Implementation Plan — REP-2908

## 1. Resumen

Reemplazar el spike de RAG jurídico (`legalRagService.js`) por un pipeline real: corpus en base de datos, embeddings de Gemini, cascada jurisdiccional en SQL, y generación de fundamento por LLM con validación determinística anti-alucinación. Solo código y migraciones versionadas en esta tarea; ninguna ejecución contra infraestructura real (sin Supabase CLI ni credenciales de Gemini en este entorno).

## 2. Repositorio inspeccionado

- Stack: Vite 6 + React 18 + Supabase (Postgres 17 + pgvector) + Vitest 3.
- Runtime: Node (frontend), Deno (Edge Functions).
- Package manager: pnpm.
- Branch base: `staging` (rama de trabajo: `feat/REP-2908-rag-juridico-de-produccion-...`, creada por `agt task:new`).
- CI actual: revisar `.github/workflows/` — no se modifica en esta tarea.

## 4. Estrategia de implementación

1. Diseñar la interfaz de embeddings/generación (`EmbeddingsClient`, `GenerationClient`) como parámetros inyectables de `legalRagService.js`, para que producción use el cliente real de Gemini y los tests usen un doble determinístico — nunca al revés (nunca cae a un corpus hardcodeado si falla la llamada real).
2. Escribir `match_knowledge_fragments` como SQL puro (no se puede probar contra Postgres real en este entorno) reflejando exactamente la consulta del docx §4.3, con comentarios explicando cada regla de la cascada.
3. Escribir la Edge Function con la misma lógica de umbral/validación que se prueba unitariamente en el lado Node, para que el contrato sea el mismo documento en dos runtimes (Deno no puede correr Vitest, así que la validación determinística se extrae a una función pura reutilizable/replicada y testeada en el lado Node).
4. Adaptar los tests de los 6 casos A–F para que verifiquen el *contrato* (qué se recupera, qué se descarta, qué pasa cuando no hay evidencia) contra el doble de prueba, no contra reglas de negocio en JS.
5. Documentar en el propio código (comentarios cortos) qué queda pendiente de ejecución real, para que Matías/Hernán sepan exactamente qué falta correr fuera de esta sesión.

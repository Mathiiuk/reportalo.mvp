# Specification — REP-3866

## 1. Objetivo
Implementar el handoff de Iván (REP-3865, `docs/Footer___Acerca_De/…/export/acerca`): página «Acerca de», footer compartido y entrada en Perfil.

## 2. Diferencias con el handoff (por cómo está armado el repo)
| Handoff | Implementación | Por qué |
|---|---|---|
| `/acerca` como HTML estático en `public/` | Ruta de React `AcercaPage` | `vercel.json` reescribe todo a `index.html` y el Service Worker manda las navegaciones al `index.html` en caché: el HTML estático no se vería |
| Web component `<rep-footer>` | Componente React `SiteFooter` con los mismos textos | Misma app, tokens `rep-*` y modo oscuro por clase `dark` |
| `/preguntas-frecuentes` | `/faq` | Ruta existente |
| `prebuild` / `predev` | `node scripts/build-info.mjs && …` dentro de `build` y `dev` | pnpm no corre pre/post scripts por defecto |
| `/assets/reportalo-icon.png` | `/logo-icon.webp` | Es el isotipo que ya usa la app |
| `rep-tokens.css`, `data-theme="dark"` | Tokens de Tailwind y clase `dark` | Sistema de diseño existente |
| Correo `info@` visible | Oculto (`SHOW_CONTACT_EMAIL = false`) | REP-3873 sin cerrar; la Planning pide no publicarlo sin prueba de recepción |
| `/privacidad` | Oculto (`SHOW_PRIVACY = false`) | La página no existe (handoff §11) |
| `/faq` protegida | Pública (decisión de Matías, 21/10) | El footer la enlaza desde páginas sin sesión y «¿Es una emergencia?» no puede pedir login |

## 3. Fuera de alcance
Texto institucional pendiente de aprobación del PO; logo UNLZ blanco para oscuro; nombre de la startup; el correo que ya mostraba la FAQ (REP-3554).

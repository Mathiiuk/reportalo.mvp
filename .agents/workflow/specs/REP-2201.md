# Especificación de Requerimientos: REP-2201

## 1. Historia de Usuario
Como ciudadano que está creando un reporte, quiero sacar o seleccionar una foto desde Reportalo para adjuntar la primera evidencia del incumplimiento observado.

---

## 2. Criterios de Aceptación

1. **CA-01 (Acción clara para capturar/adjuntar):** Desde el flujo de nuevo reporte existe una acción clara para tomar o adjuntar una fotografía.
2. **CA-02 (Invocación nativa):** En dispositivos compatibles, la PWA invoca cámara (`capture="environment"`) o selector de imagen.
3. **CA-03 (Cancelación sin pérdida de flujo):** El usuario puede cancelar o cambiar la foto sin perder el flujo.
4. **CA-04 (Estado de evidencia cargada):** Tras seleccionar/capturar una imagen se muestra un preview con metadatos y estado `CAPTURED_LOCAL`.
5. **CA-05 (Validación de archivo):** Un archivo no admitido (formato inválido o >10MB) muestra un error comprensible.
6. **CA-06 (Desacoplamiento):** La captura queda 100% desacoplada de Google Vision, Sharp y llamadas al backend.

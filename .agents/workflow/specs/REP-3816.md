# Specification — REP-3816

## 1. Objetivo
Confirmar, antes de construir `analizar-imagen-reporte` (REP-3818), que el modelo multimodal elegido admite imagen anonimizada + salida JSON estructurada con el contrato definido, y dejar una decisión técnica explícita para habilitar o bloquear esa implementación.

## 2. Problema actual
REP-3818 y REP-3817 construyen una verificación visual por fotografía sobre un contrato (`scene_summary`, `coherence`, `suggested_service_id`, `quality_flags`, `confidence_score`) que nunca se probó contra el modelo real con ese esquema. REP-3790 validó la extracción de hechos, no este contrato.

## 3. Resultado esperado
Evidencia reproducible de llamadas válidas con imagen anonimizada, esquema cumplido o fallback documentado, latencia y consumo medidos, y decisión explícita.

## 4. Alcance
### Incluido
- Spike con protocolo fijado antes de correr (`scripts/rag-local-dev/rep3816/PROTOCOLO.md`), 154 corridas sobre 14 entradas y 5 configuraciones.
- Informe `docs/REP-3816_spike-contrato-multimodal.md` con la decisión.
### No incluido
- Implementar la Edge Function (REP-3818), la base (REP-3817) o la pantalla (REP-3820).
- Modificar el RAG textual, `analizar-reporte` o el pipeline de anonimización. No se escribe en la base ni en el bucket.

## 5. Criterios de aceptación
- [x] AC-01: Evidencia reproducible de al menos una llamada válida con imagen anonimizada (112 de 112 válidas; `raw/runs.ndjson`).
- [x] AC-02: La salida cumple el esquema esperado (100 %, validación determinística).
- [x] AC-03: Decisión técnica explícita: **HABILITAR REP-3818** con `gemini-3.8-flash` + `thinkingLevel: low`; respaldos `gemini-3.7-flash` y `gemini-3.5-flash-lite`.
- [x] AC-04: Latencia y consumo registrados (mediana 2,54 s; ~1.650 tokens por foto).
- [x] AC-05: No se modifica el RAG textual ni el pipeline de anonimización.

## 6. Restricciones
Clave de Gemini solo desde el `.env`, nunca impresa. Imágenes de prueba fuera de git.

## 7. Dependencias
Punto de entrada del núcleo de verificación visual del Sprint 15. Antecedente: REP-3790.

## 8. Riesgos
Muestra pequeña y de fotos claras (ver limitaciones del informe). `confidence_score` no es una probabilidad. `coherence` no detecta discrepancia de categoría: se deriva de forma determinística.

## 9. Impacto
Sin cambios en `src/`, `supabase/` ni la base. Solo `scripts/rag-local-dev/rep3816/` y `docs/`.

## 10. Preguntas / incertidumbres
Ver «Qué habilita en REP-3818» y limitaciones del informe.

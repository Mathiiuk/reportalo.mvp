# Specification — REP-3304: Configurar Vercel Preview por Rama

## 1. Objetivo

Habilitar despliegues de vista previa (*Preview Deployments*) automatizados en Vercel para cada rama o Pull Request en el repositorio `reportalo.mvp`, permitiendo que el responsable de QA (Ivo) valide visualmente los cambios introducidos por el desarrollador/PL (Matias) de forma ágil y sin costos de licenciamiento (Vercel Free/Hobby).

## 2. Problema actual

Actualmente, las ramas de desarrollo no cuentan con un entorno en la nube donde QA pueda inspeccionar y validar interactivamente la interfaz y comportamiento antes del merge a `main`.

## 3. Resultado esperado

1. Al abrir un PR desde cualquier rama de feature (ej. `feat/...`), Vercel compila e implementa automáticamente un entorno efímero.
2. Vercel publica un comentario directo en el Pull Request de GitHub con la URL pública del preview (ej. `https://reportalo-mvp-git-feat-...-mathiiuk.vercel.app`).
3. Ivo (QA) accede a la URL sin necesidad de credenciales de Vercel y valida el entregable.
4. Al hacer push de nuevos commits al PR, la URL de preview se actualiza automáticamente.

## 4. Alcance

### Incluido
- Configuración de `vercel.json` compatible con despliegues estáticos y futuros frameworks.
- Guía operativa para la vinculación en el panel de Vercel y checklist de validación para QA.
- Documentación completa del ciclo de vida de la tarea según la skill del proyecto.

### No incluido
- Código de aplicación frontend o backend (se abordará en tareas posteriores al definir el stack).
- Asignación de dominio personalizado para previews (se utilizará el subdominio `.vercel.app` provisto por defecto).

## 5. Criterios de aceptación

- [ ] **AC-01**: Integración de Git con Vercel configurada en el repositorio `Mathiiuk/reportalo.mvp`.
- [ ] **AC-02**: Todo Pull Request abierto hacia `main` dispara automáticamente una compilación de Preview en Vercel.
- [ ] **AC-03**: El bot de Vercel publica la URL del Preview como comentario en el PR de GitHub.
- [ ] **AC-04**: La URL del preview es accesible públicamente sin pantallas de bloqueo ni requerir inicio de sesión para el rol de QA.

## 6. Restricciones

- **Plan Vercel Hobby / Free**: La cuenta de Vercel pertenece a Matias Krepchuk. No se agregan miembros pagos; la colaboración con QA se realiza a través de las URLs públicas y los comentarios en GitHub PRs.

## 7. Dependencias

- Repositorio GitHub: `Mathiiuk/reportalo.mvp`
- Cuenta Vercel personal de Matias Krepchuk vinculada a GitHub.

## 8. Riesgos y Mitigaciones

| Riesgo | Impacto | Mitigación |
| :--- | :--- | :--- |
| Configuración de build incompatible | Bajo | `vercel.json` se mantiene minimalista para no interferir con futuros frameworks. |
| QA no encuentra el enlace de prueba | Bajo | El bot de Vercel en GitHub publica el enlace en el cuerpo del PR automáticamente. |

# Especificación de Requerimientos: REP-2600

## 1. Historia de Usuario
Como ciudadano autenticado, quiero acceder a `/mapa` como pantalla principal para visualizar reportes cercanos, orientarme dentro de Reportalo y continuar hacia las funciones principales de la aplicación.

---

## 2. Criterios de Aceptación

1. **CA-01 (Acceso a /mapa):** Después de autenticarse, el ciudadano puede acceder a la ruta `/mapa`.
2. **CA-02 (Pantalla principal autenticada):** El mapa se presenta como pantalla principal de la experiencia ciudadana autenticada.
3. **CA-03 (Reportes visibles georreferenciados):** Se muestran reportes disponibles del ambiente de prueba con ubicación visible sobre CABA y Avellaneda.
4. **CA-04 (Identificación de categoría):** El usuario puede identificar al menos la categoría o tipo básico de cada reporte mostrado a través de marcadores y tarjeta interactiva.
5. **CA-05 (Estado vacío reutilizable):** Si no existen reportes para mostrar (o por filtro), se presenta un estado vacío comprensible y reutilizable.
6. **CA-06 (Navegación principal):** La pantalla ofrece navegación hacia *Perfil* y *Mis reportes*.
7. **CA-07 (Acción de nuevo reporte):** La pantalla deja disponible una acción clara para iniciar un nuevo reporte, cuya implementación funcional se abordará en Sprint 11.
8. **CA-08 (Comportamiento responsive):** La experiencia funciona correctamente en mobile y desktop.
9. **CA-09 (Demostrable en staging):** El incremento puede demostrarse en staging.

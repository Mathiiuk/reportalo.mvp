# Definition of Done

Una tarea puede marcarse como `DONE` sólo cuando los checks aplicables están completos.

- [ ] Requerimiento entendido
- [ ] Specification creada
- [ ] Implementation Plan creado
- [ ] Task manifest actualizado
- [ ] Cambios implementados
- [ ] Código revisado
- [ ] Lint PASS
- [ ] Typecheck PASS, si aplica
- [ ] Unit tests PASS
- [ ] Integration tests PASS, si aplica
- [ ] E2E PASS, si aplica
- [ ] Build PASS
- [ ] Security gates PASS, si aplica
- [ ] PR creado
- [ ] CI PASS
- [ ] Review / policy PASS
- [ ] Merge realizado
- [ ] Staging verificado, si aplica
- [ ] Production desplegada, si aplica
- [ ] Health check PASS
- [ ] Rollback probado o estrategia verificada
- [ ] Documentación actualizada
- [ ] Execution Report generado
- [ ] Sin errores críticos conocidos
